# 样式规范

目标是 VS Code 式的紧凑桌面工具：浅底、细线、低对比文字，强调色只用于选中和焦点。

## 色彩

浅色是默认主题。`html` 上设置 `data-theme="light" | "dark"`，只切换变量，不改结构。

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#ffffff` | `#1e1e1e` | 页面、编辑器 |
| `--toolbar` | `#f7f8fa` | `#252526` | 标题栏、工具条、状态栏 |
| `--panel` | `#ffffff` | `#1e1e1e` | 菜单、浮层 |
| `--line` | `#e6e8eb` | `#3c3c3c` | 分割线、描边 |
| `--gutter` | `#f4f5f7` | `#252526` | 行号槽 |
| `--text` | `#1f2328` | `#d4d4d4` | 正文 |
| `--muted` | `#5b6470` | `#9da5b4` | 次级文字、未激活按钮 |
| `--faint` | `#8b949e` | `#6e7681` | 辅助信息、快捷键 |
| `--accent` | `#1677ff` | `#4fc1ff` | 焦点、选中页签 |
| `--accent-soft` | `#e8f1ff` | `rgba(79,193,255,.14)` | 选中项浅底 |
| `--hover` | `rgba(22,119,255,.08)` | `rgba(255,255,255,.06)` | 悬停 |
| `--selected` | `#dbeafe` | `rgba(79,193,255,.18)` | 选中块 |
| `--false` | `#c0392b` | `#f14c4c` | 错误、删除 |

JSON 语义色单独使用，不拿来做按钮：

| 令牌 | 浅色 | 深色 |
| --- | --- | --- |
| `--key` | `#0550ae` | `#9cdcfe` |
| `--string` | `#0a7a3e` | `#ce9178` |
| `--number` | `#b35c00` | `#b5cea8` |
| `--true` | `#0a7a3e` | `#4ec9b0` |
| `--null` | `#8b949e` | `#808080` |

关闭按钮悬停固定 `#e81123` 底、白色图标。不要改成主题色。

## 字体

- 界面：`"Segoe UI", Inter, sans-serif`
- 代码、树、路径：`"Cascadia Code", "JetBrains Mono", Consolas, monospace`
- 菜单、工具按钮、输入框：12.5px
- 状态栏、辅助文字：12px
- 快捷键：11px
- 空状态标题：28px，正文用 `--muted`

控件继承 `font: inherit`，不要在按钮上再设一套字体。

## 骨架

应用根节点是三行网格：

| 区域 | 高度 |
| --- | --- |
| 标题栏 | 36px |
| 工作区 | 剩余高度 |
| 状态栏 | 26px |

标题栏左起 8px 内放 20×20 logo（圆角 5px），接着是菜单。右侧窗口按钮每个 46×36。空白处可拖动窗口。

工作区左右分栏。左栏最小 360px，约占 58%；右栏最小 280px；分隔条 6px，悬停变 `--accent`。左栏自己再分成 36px 工具条和编辑器。右栏同样是 36px 页签条加内容。

## 控件

按钮默认无边框、透明底。文字用 `--muted`，悬停变 `--hover` 底和 `--text`。

| 控件 | 尺寸 | 圆角 |
| --- | --- | --- |
| 工具按钮 `.cmd` | 高 26px，左右 10px | 4px |
| 页签 `.view-tab` | 高 26px，左右 10px | 4px |
| 搜索框 | 高 26px | 4px |
| 菜单项 | 最小高 28px | 3px |
| 下拉选项 | 最小高 32px | 8px |
| 状态栏按钮 | 高 22px | 4px |
| 主按钮 `.primary` | 高 32px | 7px |

页签和工具按钮必须 `white-space: nowrap`，并且 `flex: 0 0 auto`。窗口变窄时压缩搜索框，不把中文折成竖排。页签选中用强调色文字，不加下划线。

工具条分组用 1×14px 的 `--line` 分隔，左右外边距 6px。

## 浮层

- 菜单面板：贴着触发器下方，左边对齐，最小宽 248px，内边距 4px，圆角只留下方 6px。
- 搜索结果、模式菜单：距触发器 6px，圆角 6px 或 10px，投影 `--shadow`。
- 选中项用 `--accent-soft` 底和 `--accent` 字，不用整块实心强调色。
- 模态框居中，标题栏和底栏与窗口标题栏同一高度节奏，内容区用 `--line` 分隔。

## 图标

图标用 16×16 viewBox 的描边 SVG，显示尺寸 13px 或 14px。描边 1.4 或 1.5，`round` 端点。颜色跟随 `currentColor`。窗口控制图标用 10px、描边 1.2。

## 反馈

- 有效状态不抢颜色；错误用 `--false`，并在元素上保留完整信息作 tooltip。
- 删除行浅红底加 3px 红色左边线；新增行浅绿底加 3px 绿色左边线。
- 拖放遮罩：距窗口 12px，2px 虚线 `--accent`，圆角 16px，字号 24px。
- 滚动条保持系统样式，不自定义。

## 新软件最小清单

1. 复制 [tokens.css](tokens.css)，保留变量名。
2. 做 36 / 内容 / 26 的窗口骨架和无边框标题栏。
3. 菜单、工具条、页签、状态栏按上面的高度和圆角。
4. 同时提供浅色和深色，切换时只改 `data-theme`。
5. logo 用圆角小图放在标题栏，不在工作区再放大放一次。
